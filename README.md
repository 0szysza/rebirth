# Rebirth Calculator

A static rebirth goal calculator for one, two or three accounts: Main, Alt 1 and Alt 2. It follows the visual style of [TrackCCU](https://0szysza.github.io/trackccu/).

Enter the current and target rebirth counts, then set how many rebirths you gain over a custom number of minutes. The page estimates elapsed grind time, finish time and the rebirth count at a chosen forecast time. Calculations assume a constant pace without breaks.

The initial Main and Alt 1 values are editable examples. Alt 2 starts empty. Calculations run in the browser and are not saved. The Tools menu links to TrackCCU.

Published with GitHub Pages at <https://0szysza.github.io/rebirth/>.

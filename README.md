# BGSI Rebirth Calculator

A static rebirth goal calculator for one, two or three accounts: Main, Account 1 and Account 2. It follows the visual style of [TrackCCU](https://0szysza.github.io/trackccu/).

Enter the current and target rebirth counts, then set how many rebirths you gain over a custom number of minutes. The page estimates the remaining grind time and finish time from the current time. Calculations assume a constant pace without breaks.

The initial Main and Account 1 values are editable examples. Account 2 starts empty and uses TrackCCU's pink accent. Entered values and the selected number of accounts are saved in localStorage on this device. The Tools menu links to TrackCCU, and the header's back arrow opens the tool hub.

Hover, tap, or focus a progress bar and use the arrow keys to inspect a point. The tooltip shows its rebirth count, progress to 0.1%, estimated time to reach that point, and the goal's finish time. All modes use full-width account cards stacked vertically, with inputs and results side by side on desktop.

Published with GitHub Pages at <https://0szysza.github.io/rebirth/>.

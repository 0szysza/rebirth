# BGSI Rebirth Calculator

A static rebirth goal calculator for one, two or three accounts: Main, Alt 1 and Alt 2. It follows the visual style of [TrackCCU](https://0szysza.github.io/trackccu/).

Enter the current and target rebirth counts, then set how many rebirths you gain over a custom number of minutes. The page estimates the remaining grind time and finish time from the current time. Calculations assume a constant pace without breaks.

The initial Main and Alt 1 values are editable examples. Alt 2 starts empty and uses TrackCCU's pink accent. Entered values and the selected number of accounts are saved in localStorage on this device. The Tools menu links to TrackCCU.

Hover, tap, or focus a progress bar and use the arrow keys to inspect a point. The tooltip shows its rebirth count, progress to 0.1%, estimated time to reach that point, and the goal's finish time. The one-account layout uses the full page width.

Published with GitHub Pages at <https://0szysza.github.io/rebirth/>.
